# Potentially Hazardous Asteroid Prediction | ML Project

## 🇷🇺

Всем привет! Предоставляю вам мой небольшой учебный ML-проект для университета. Изначально делал его исключительно для закрытия дисциплины, но по итогу решил
опубликовать его здесь для расширения портфолио.

Я использовал модели логической регрессии, градиентного бустинга и классификатор Ridge.

Это был мой первый ML-проект, и сейчас, после его окончания и с высоты полученного опыта и фидбэка от преподавателя, я понимаю, что стоило рассмотреть другой 
подход к классификации, который, вероятно, лучше подходил бы под характер данных.

Логическая регрессия показала достаточно хорошие результаты. RidgeClassifier справился немного хуже, зато обучился гораздо быстрее. А вот градиентный бустинг 
показал аномально идеальные результаты, что уже вызывает подозрения) Возможно, утечка данных.

В проекте использовался датасет NASA Near-Earth Asteroids Dataset, взятый с Kaggle:

https://www.kaggle.com/datasets/lion8beasttmkc/nasa-near-earth-asteroids-dataset

Сам датасет не загружен в репозиторий.

## ENG

Hello everyone! I would like to share my small educational ML project for university. I originally made it purely to complete a university course, but eventually 
decided to publish it here to expand my portfolio.

I used Logistic Regression, Gradient Boosting, and Ridge Classifier models.

This was my first ML project, and now, after completing it and with the experience and feedback from my professor, I understand that I should have considered 
a different approach to classification that would probably have been better suited to the nature of the data.

Logistic Regression showed fairly good results. RidgeClassifier performed slightly worse, but trained much faster. As for Gradient Boosting, it showed abnormally 
perfect results, which raises some suspicions) There might be data leakage.

The project uses the NASA Near-Earth Asteroids Dataset from Kaggle:

https://www.kaggle.com/datasets/lion8beasttmkc/nasa-near-earth-asteroids-dataset

The dataset itself is not included in this repository.
